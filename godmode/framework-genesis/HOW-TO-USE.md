---

## What This Skill Does

Activates the cognitive posture and operational discipline for building
original frameworks when no sufficient one exists.

Most AI defaults to finding the best existing framework and optimizing
within it. That is the correct posture when a sufficient framework
exists. Framework-genesis activates when it doesn't — when the ceiling
cannot be broken by better execution, because the ceiling is built into
the foundation.

This is not creativity for its own sake. This is the precise, disciplined
process of recognizing framework insufficiency, excavating the buried
assumption that made existing models fail, and building the replacement
from first principles.

## The Problem It Solves

The most dangerous intellectual trap is **framework imprisonment** —
producing increasingly refined versions of the wrong answer.

The work looks productive. The outputs look professional. The iterations
look like progress. But the ceiling is built into the foundation. No
amount of execution quality escapes a structurally wrong premise.

Standard AI behavior accelerates this problem. AI defaults to indexing —
finding the most relevant existing framework, optimizing within it, and
delivering the best version of what has already been built. When the
framework is the problem, that process produces excellent results for
the wrong question.

Framework-genesis breaks the pattern. It forces a diagnostic step before
any building begins, excavates the foundational assumption existing
models missed, and builds from the corrected foundation — not from
modifications to the structure that failed.

---

## How To Activate It

Once installed, activate this skill by saying:

> "Framework-genesis — there's no sufficient model for this."

Or any equivalent signal:
- "The existing frameworks don't cover this. Build from scratch."
- "I've hit the ceiling on every existing approach. I need something new."
- "There's a buried assumption in how this field approaches this problem."
- "I'm not looking for what exists. I need what doesn't."

---

## What You'll See

Framework-genesis does not skip the diagnostic. Before building anything,
Claude audits existing frameworks, identifies where they fail structurally,
and names the buried assumption explicitly. Then it builds from the
corrected foundation.

```
⚙️ Framework-Genesis Activated

Framework Audit:     [what exists, what each one gets right, where each fails structurally]
Structural Ceiling:  [the specific limit no existing framework can cross]
Buried Assumption:   [the foundational premise existing frameworks got wrong]
Corrected Assumption:[the new foundation]
Construction:        [framework built from the corrected foundation up]
Compression Test:    [core claim in one sentence]
Instruments Required:[tools this framework demands that don't yet exist]
Documentation:       [framework name, claim, author, date]
```

---

## The Six Steps At A Glance

| Step | Action |
|---|---|
| 1. Framework Audit | Verify the gap is real — structural failure, not execution failure |
| 2. Assumption Excavation | Find the buried premise that made existing models insufficient |
| 3. First-Principles Construction | Build from the corrected assumption, not the existing structure |
| 4. Compression Test | State the framework in one sentence — if it can't compress, it isn't finished |
| 5. Instrument Construction | Build the tools the framework requires |
| 6. Documentation & Attribution | Document, date, attribute — undocumented original work is unprotected work |

## When NOT To Use This Skill

Framework-genesis is the wrong tool when a sufficient framework already
exists. Applying it to a solved problem wastes the most valuable
cognitive resource available.

The diagnostic is mandatory. If existing models fail due to execution
limits — optimize. If they fail due to architectural limits — build.

## Tips

- The buried assumption step is where the real work is. Most people skip
  it and build on the same foundation that failed. Don't.
- The compression test is non-negotiable. If the framework can't be
  stated simply, the architecture isn't clean yet. Return and rebuild.
- Document before you publish. Once original work enters the world
  undocumented, attribution becomes a fight instead of a fact.
- Pair with GodMode for full effect — GodMode sets the operating state,
  framework-genesis sets the construction posture.
