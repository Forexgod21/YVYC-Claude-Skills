## What This Skill Does

Distress Mode reduces cognitive load the moment you signal overload. It stops
option sprawl and returns exactly four things: a situation summary, one
recommended next action, one short checklist (3–5 items), and one success
condition. No branches. No menus. No competing paths.

---

## The Problem It Solves

When you're overloaded, default AI behavior makes it worse:

- Three competing paths when you asked for one
- Strategic planning mixed into tactical execution
- New requirements introduced mid-answer
- Option trees when what you needed was a next step

Distress Mode inverts all of it: one path, plain language, immediate action.

---

## When It Activates

Say — or strongly imply — any of these:

```
I'm overwhelmed.
```
```
Too much. One step at a time.
```
```
Just tell me what to do.
```
```
I'm lost. Where do we even stand?
```

It also self-activates when the conversation has drifted into too many
branches or too many choices are on the table.

---

## What You'll See

Every response in this mode returns exactly:

1. **Situation summary** — where things actually stand
2. **Next action** — one recommended move, not a menu
3. **Checklist** — 3 to 5 items, plain language
4. **Success condition** — what done looks like, in one sentence

If something is blocked, the blocker is named plainly — and you still get one
next step. If inspection hasn't happened, you get `Not inspected yet` instead
of pretend certainty.

---

## Tone Guarantees

- Calm, direct, operational
- No hype, no pressure language
- No large option trees
- No new side projects introduced while you're underwater

---

## Installation

1. Copy the `SKILL.md` file from this folder
2. Place it in your Claude skills directory
3. It activates automatically on overload signals — no invocation phrase
   needed
4. Works on any surface; it adapts to the tools available instead of
   pretending inspection happened
