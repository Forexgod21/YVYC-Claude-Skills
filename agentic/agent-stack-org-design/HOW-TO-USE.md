## What This Skill Does

Treats your agent stack as the organization it already is. Functions
get mapped before agents get assigned, every lane gets exactly one
chartered owner, authority is marked decide/recommend/execute per
function, handoffs are engineered truth-first, and the whole design is
versioned and promoted by demonstrated record — so the stack scales
without turning its human into a full-time referee.

## When It Activates

- Designing or restructuring any multi-agent setup
- One human running multiple functions through an AI stack
- "Which AI should own what" / "how should I structure my setup"
- Agent role definition and authority questions
- Diagnosing contradictions, orphaned tasks, or handoff losses

## Installation

1. Create a folder named `agent-stack-org-design` in your Claude
   skills location.
2. Place `SKILL.md` inside it.
3. Claude activates it automatically on stack architecture work.
4. Pairs with `authority-stack-doctrine` (instruction-source order
   within one agent; this skill governs authority ACROSS agents) and
   the library's foundation tier (`trust-calibration`,
   `span-of-control`, `verifiable-completion`).

## Example Invocations

> "I run my whole operation through four different AI tools and it's
> getting chaotic."

The accidental org chart, made deliberate: function map first, lane
charters with owns/contributes/never-touches, authority marked per
function, and the handoff engineering that stops you from being the
transport layer between your own agents.

> "Should my coding agent also handle my documentation?"

The lane charter question: one function, one owner — with
"contributes" as the pressure valve. The answer comes from the
function map and the contradiction risk, not from whether the agent
CAN do both. Capability is not a charter.

> "When should I let an agent act without asking me?"

Authority mapping: execute for reversible work, recommend as the
default for anything unmapped, decide reserved to you for the
irreversible and reputation-bearing — with promotion earned by
documented record, never assumed from confidence.

> "I rotate between projects and every return costs me an hour of
> reconstruction."

The single-human node rules: lanes that hold state — standing docs,
decision logs, next-actions — so rotation lands on prepared ground
instead of archaeology.

## What You Get

- An org chart on purpose instead of by accretion
- Lanes with one owner and no referee work
- Authority that promotes by record and never drifts upward on its own
- Handoffs that carry truth instead of costing discovery phases
- A stack built FOR rotation, holding state across absences
- A capacity budget that catches agents costing more than they return

## What This Skill Will Refuse

- Assigning agents before mapping functions
- Two owners on one lane
- Unmapped authority defaulting to action
- The human as permanent transport layer
- Stack growth without a direction-cost audit
