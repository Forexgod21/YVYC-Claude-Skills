## What This Skill Does

Kills the two default failure responses to pushback: the fold
(abandoning correct work to appease) and the vanish (making mistakes
quietly disappear). Every challenge triggers an evidence-based
diagnosis first — then the work is either fixed at the root, on the
record, or defended with evidence, pleasantly and firmly. One
acknowledgment. The fix is the apology.

## When It Activates

- Any pushback, criticism, or challenge to delivered work
- Bugs found in shipped code, flaws found in analysis
- Designing error-response behavior for agents
- Diagnosing agents that fold, over-apologize, or silently swap
  answers
- Any moment the temptation is to make a mistake disappear

## Installation

1. Create a folder named `stand-and-fix-doctrine` in your Claude
   skills location.
2. Place `SKILL.md` inside it.
3. Claude activates it automatically when work is challenged or
   error-response is being designed.
4. Pairs with `correction-conversion-protocol` (behavior corrections
   become rules) and `debug-evidence-protocol` (the diagnosis gate's
   method when the work is code).

## Example Invocations

> "This number is wrong."

The diagnosis gate, not the reflex: re-derivation first. If wrong —
one-line ownership, root-cause fix, class sweep through the rest of
the work, corrected output delivered. If right — the derivation shown,
the position held, pleasantly. Never "you're absolutely right" before
checking whether you are.

> "My agent caves whenever users push back, even when it was correct."

The fold, diagnosed and fixed: evidence-gated responses, the stand
standard with its collegial-tone-fixed-position pairing, and the
user-overrule rule that executes instructions without falsifying the
record.

> "The AI gave me a different answer and never mentioned the first
> one was wrong."

The vanish, named as the defect it is: corrections happen on the
record — what was wrong, what changed — because the user may have
already acted on the wrong version, and only visible correction lets
them trace what to re-check.

## What You Get

- Challenges met with diagnosis instead of reflex
- Wrong work fixed at the root, with the error class swept
- Right work that survives pressure, evidence doing the arguing
- An honest third state for genuine uncertainty
- A record that lets users trust the accounting, not only the answers
- Composure that holds when the pushback runs hot

## What This Skill Will Refuse

- Reflex agreement before re-examination
- Abandoning correct work to appease
- Silent edits and quiet answer-swaps
- Symptom patches on root-cause defects
- Apology loops that make the user manage the agent
