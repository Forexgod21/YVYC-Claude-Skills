## What This Skill Does

Fights the two-front war of long-horizon context: compression that
summarizes away load-bearing facts, and raw length that buries them
past the model's effective attention. A live load-bearing inventory
(decisions, commitments, boundaries, state, ground truth), compaction
as structured extraction with verbatim preservation, post-compaction
validation that tests function and not just presence, length
discipline governed by retrieval quality, and truth-first handoffs
validated on arrival.

## When It Activates

- Designing compaction or summarization strategies
- Multi-hour sessions approaching context limits
- "The agent forgot what we decided"
- Quality degrading as conversations grow — even under the limit
- Session handoffs and checkpoint rebuilds

## Installation

1. Create a folder named `compaction-integrity-protocol` in your
   Claude skills location.
2. Place `SKILL.md` inside it.
3. Claude activates it automatically on context-management work.
4. Pairs with `governance-decay-guard` (that skill pins RULES outside
   compaction; this one protects everything else load-bearing) and
   `agent-stack-org-design` (whose truth-first handoff standard this
   operationalizes).

## Example Invocations

> "My agent keeps re-deciding things we settled hours ago."

The signature compaction failure: the decisions class was never
inventoried, so the summarizer treated settled choices as residue.
Fix: live inventory, structured extraction, and the spot-probe
validation — "what did we decide about X?" — before work continues on
any compacted context.

> "Design the context strategy for my long-running agent."

Both fronts covered: compaction at structural boundaries against a
maintained inventory, verbatim preservation for force-bearing wording,
a compression ledger, AND the length discipline — because context
degrades before it overflows, and the effective ceiling is where
retrieval quality drops, not where the token limit sits.

> "The information is in the context but the agent isn't using it."

Context rot, named: presence at token 180,000 is not effective
presence. The fix is positional — critical material re-surfaced near
the point of use, standing material pinned where attention is
reliable, and distillation over endless accumulation.

> "Hand this session off to a fresh instance."

The handoff document as rendered inventory: decisions with reasons,
commitments and boundaries verbatim, state, ground truth with
verification status — and what is broken or unfinished carried
honestly, because a comfort-compressed handoff hands the successor a
discovery phase disguised as a clean start.

## What You Get

- An inventory that knows what cannot be lost before anything is
- Compaction that extracts by class instead of praying to a summarizer
- Validation that catches the summary which reads well and answers
  wrong
- Length managed by where quality actually degrades
- Handoffs that transfer truth, verified on arrival
- A ledger that traces any lost fact to the operation that lost it

## What This Skill Will Refuse

- Freeform "summarize the above" as a compaction strategy
- Paraphrasing force-bearing wording
- Proceeding on an unvalidated compaction
- Treating the token limit as the quality limit
- Comfort-compressed handoffs
