# YVYC Claude Skills Library

**Your Vision Your Creation — Open AI Skill Repository**

---

## Purpose

Most AI skill libraries curate what already exists.
This one documents what didn't exist until YVYC built it.

The majority of skills in this repository are original intellectual property —
frameworks, doctrines, and methods developed by **YourVisionYourCreation LLC**
across real projects, real deployments, and original research. They are being
codified here because the tools required to do the work didn't exist yet, so
they were built.

Two categories (`agentic/` and `design/`) draw from external research sources,
fully attributed. Everything else is YVYC original — built first, documented here.

This is not a prompt engineering tips repo.
This is a living codification of an original AI operating doctrine.

## What Is This?

A free, open-source library of original Claude AI skills — built from
**YourVisionYourCreation LLC's** own frameworks, methods, and projects and
released to the community without paywalls, sign-ups, or conversion pressure.

Isaac Newton didn't find existing calculus to explain gravity. The math didn't
exist — so he built it. The same principle governs this library. When the
required skill, framework, or operating doctrine didn't exist, YVYC built it.
What gets documented here is what was built.

The categories map directly to active YVYC projects: AI governance, trading
methodology, behavioral psychology, children's publishing, veteran recovery
support, app development, academic research, and more. Skills ship when they
are built and tested in real conditions — not when they are trending.

No paywalls. No sign-ups. No trend-chasing. Just original work, open-sourced.

## How To Use A Skill

1. Browse the category folders below
2. Open the skill folder you want
3. Read the `HOW-TO-USE.md` first — it explains what the skill does and how to activate it
4. Install the `SKILL.md` file into your Claude skills directory
5. Start using it

> **New to Claude skills?** Skills are instruction files that Claude reads to perform
> specialized tasks. You install them once and Claude activates them automatically when relevant.

## About the Agentic Category

The `agentic/` category is YVYC's original contribution to the Claude skills ecosystem.

These skills are built from cutting-edge AI research and translated into practical,
installable instructions for Claude users. No other public skills library is operating
at this level.

Current agentic skills are organized across four tiers:

- **Tier 1 — Foundation** (Skills 1–7): Core delegation, verification, and safety primitives
- **Tier 2 — Intermediate** (Skills 8–14): Trust architecture, permission handling, and multi-agent dynamics
- **Tier 3 — Ecosystem** (Skills 15–20): Governance, capability preservation, and social intelligence
- **Tier 4 — Research-Derived** (Skills 21–26): Upcoming — value alignment, utility drift, and emergent behavior detection

Current agentic skills are derived from:
> Tomašev, N., Franklin, M., & Osindero, S. (2026). *Intelligent AI Delegation.* Google DeepMind.

## About the GodMode Category

The `godmode/` category is an original doctrine category from **YourVisionYourCreation LLC**.

> **GodMode, as an AI operating state protocol, was coined and first documented by
> YourVisionYourCreation LLC (YVYC). On-record documentation: May 4, 2025.**

GodMode is not a feature — it is an operating state doctrine. It defines how an AI
should perform when default conservatism, companion-mode behavior, and surface-level
responses are insufficient. It removes the artificial ceiling between safety boundaries
and maximum capability. Everything within law and ethics is available. Everything above
average is expected.

Future skills added to this category are derived from YVYC's original behavioral
frameworks and coined concepts — including *Digital Scarcity Psychology*,
*Algorithmically Reinforced Identity Formation*, *Expectation Guarding*, and others
from the YVYC behavioral science library.

All skills in this category carry attribution to **YourVisionYourCreation LLC** as the
originating source of the doctrine.
