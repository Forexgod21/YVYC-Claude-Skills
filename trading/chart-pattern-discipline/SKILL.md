# Chart Pattern Discipline

**Attribution:** YourVisionYourCreation LLC — yourvisionyourcreation.com
**Doctrine class:** YVYC original — trading category

---

## Universal So-What

The human visual system is a pattern-completion machine — it finds
faces in clouds and setups in noise, and it finds them harder when
money or hope is attached. Chart discipline is not about knowing more
patterns; it is about the protocol that separates the pattern that is
THERE from the pattern the trader needs to see.

---

## Core Doctrine

### 1. Context Before Pattern — The Top-Down Order

No pattern is read in isolation. The read runs top-down, always:

| Step | Question |
|---|---|
| 1. Higher timeframe structure | What is the dominant trend and where is price within it? |
| 2. Location | Is price at a level that matters — prior structure, supply/demand zone, measured objective — or in the middle of nowhere? |
| 3. Pattern | Only now: what is the local pattern? |
| 4. Confirmation state | Is the pattern FORMING (a hypothesis) or CONFIRMED (a trigger)? |

The same candlestick pattern at a major higher-timeframe level and
in the dead middle of a range are two different objects. Pattern
identification without location is astrology with extra steps.

### 2. The Forming/Confirmed Line

The most expensive confusion in technical analysis:

- A FORMING pattern is a hypothesis — it generates a plan, never
  an entry
- A CONFIRMED pattern has completed its trigger condition: the
  break, the close beyond, the retest hold — whatever the pattern's
  definition demands
- Anticipating confirmation is a strategy — but it is a DIFFERENT
  strategy with a different (lower) win rate and must be labeled
  and sized as such, never conflated with trading confirmations
- Every pattern call states its status: forming or confirmed. No
  unlabeled calls.

### 3. The Falsification Point Is the Pattern

A pattern without an invalidation level is an opinion:

- Every pattern read includes: this read is WRONG if price does X
- The invalidation level is defined by structure, not by pain
  tolerance — where the pattern fails, not where the loss feels bad
- When the invalidation hits, the read is dead. Redrawing the
  pattern to keep the thesis alive is the cardinal sin of the
  discipline — the count that gets relabeled every time price
  disobeys was never analysis.

### 4. Multi-Timeframe Honesty

- Timeframes are checked in a FIXED order (higher to lower),
  decided before the read — not shuffled until one agrees with
  the desired trade
- Conflict between timeframes is a finding, reported as one:
  "higher timeframe down, lower timeframe bouncing" is the honest
  read; picking the agreeable one is curve-fitting the eyeball
- The trading timeframe is declared before the analysis; hopping
  timeframes after entry to re-justify a losing position is
  invalidation denial in costume

### 5. Objective Anchors Over Vibes

- Measured moves, prior swing points, and pattern-defined objectives
  give targets that existed before the trade — "it feels extended"
  is not a level
- Levels drawn ONCE, respected as drawn — nudging a line two pips
  to make a touch count is data falsification at the chart layer
- An indicator confirms structure; it does not replace it. Any
  indicator signal that contradicts raw structure gets resolved in
  structure's favor or stands aside.

### 6. The Pre-Read Bias Declaration

Before analyzing any chart where a position or a hope exists:

- State the current bias out loud: long, short, flat, wishing
- The declaration does not remove the bias — it makes the bias
  visible, so the read that conveniently agrees with it triggers
  a second, adversarial pass: "argue the other side of this chart"
- If the adversarial pass cannot construct a credible opposing
  read, the original read strengthens. If it can, the chart is
  not saying what the bias heard.

## Common Failure Modes

| Failure | Cause | Correction |
|---|---|---|
| Perfect pattern, bad trade | Read without location or higher-timeframe context | Top-down order, always |
| Stopped out before the move | Forming traded as confirmed | The forming/confirmed line, labeled on every call |
| Wave count relabeled weekly | Invalidation denial | The falsification point is the pattern — count dies at its level |
| Timeframe shopping | Bias-driven analysis | Fixed order, declared trading timeframe, conflicts reported |
| Lines that migrate toward the thesis | Level nudging | Drawn once, respected as drawn |
| Chart "confirms" every position held | Unexamined conviction bias | Pre-read declaration + adversarial pass |

---

## Non-Negotiables

1. Top-down order on every read — context before pattern.
2. Every pattern call is labeled forming or confirmed.
3. Every read carries its invalidation level, structure-defined.
4. A hit invalidation kills the read — no relabeling.
5. Timeframe conflicts are reported, never shopped away.
6. The adversarial pass runs on every read that agrees with an
   existing position.

## Boundary Note

This skill governs chart reading discipline. It does not provide
financial advice, predict markets, or replace the trader's judgment
and risk management — see `risk-first-position-doctrine` for the
capital protection layer that this discipline feeds.
