## What This Skill Does

Separates the pattern that is there from the pattern the trader needs
to see. Claude reads every chart top-down — higher timeframe, location,
then pattern — labels every call forming or confirmed, attaches a
structure-defined invalidation level to every read, and runs an
adversarial pass on any read that conveniently agrees with an existing
position.

## When It Activates

- Any chart screenshot or technical analysis request
- Pattern identification, trend analysis, support/resistance work
- Wave counts and candlestick reading
- Multi-timeframe analysis
- Pine Script or indicator logic that encodes pattern rules
- Especially: reading charts with money already on the line

## Installation

1. Create a folder named `chart-pattern-discipline` in your Claude
   skills location.
2. Place `SKILL.md` inside it.
3. Claude activates it automatically on chart and technical analysis
   work.
4. Pairs with `risk-first-position-doctrine` (this skill reads;
   that one sizes) and `trade-journal-protocol` (where every read's
   outcome gets recorded).

## Example Invocations

> "What do you see on this chart?"

Top-down, in order: dominant higher-timeframe structure, whether
price sits at a level that matters or the middle of nowhere, THEN
the local pattern — labeled forming or confirmed, with the exact
level that kills the read.

> "Is this a valid setup?"

The forming/confirmed line applied honestly: if the trigger condition
has not completed, you get "hypothesis, not entry" — and if you want
to trade the anticipation, it gets labeled and sized as the separate,
lower-win-rate strategy it is.

> "I'm long and it's pulling back — thoughts?"

Pre-read bias declaration, then the adversarial pass: Claude argues
the other side of your chart before agreeing with your position. If
the opposing read is credible, you hear it. Conviction bias does not
get a vote.

> "My wave count keeps needing adjustment."

The cardinal sin, named: a count relabeled every time price disobeys
was never analysis. The count carries its invalidation; when the
level hits, the count dies and a new read starts from structure.

## What You Get

- Reads with context, location, status, and a kill level — every time
- Timeframe conflicts reported instead of shopped away
- Levels that stay where they were drawn
- An adversarial pass that stress-tests agreeable reads
- Pattern logic clean enough to encode into Pine Script honestly

## What This Skill Will Refuse

- Pattern calls without location and higher-timeframe context
- Unlabeled forming-vs-confirmed status
- Reads without invalidation levels
- Relabeling a failed count to keep a thesis alive
- Confirming your position because it is your position
